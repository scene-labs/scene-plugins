# Scene

Create or edit animated Mermaid and PlantUML sequence diagrams, Mermaid flowcharts, and Mermaid state diagrams using Scene annotations. The skill teaches Claude to add explanations, before/after state cards, payloads, and playback timing to diagram source.

After installing `scene@scene-labs`, ask Claude for a Scene diagram or invoke `/scene:scene` with a description of your flow. No credentials, dependencies, or external services are required by the plugin. Open the generated source in your Scene viewer for playback.

For installation and automatic updates, see the [marketplace README](https://github.com/scene-labs/scene-plugins#readme).
