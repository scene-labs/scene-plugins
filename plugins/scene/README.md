# Scene

Create or edit animated Mermaid and PlantUML sequence diagrams, Mermaid flowcharts, and Mermaid state diagrams using Scene annotations. The skill teaches your agent to add explanations, before/after state cards, payloads, and playback timing to diagram source.

Install `scene@scene-labs` in Claude Code or Codex and ask your agent for a Scene diagram. In Claude Code, you can also invoke `/scene:scene` with a description of your flow. No credentials, dependencies, or external services are required by the plugin. Open the generated source in your Scene viewer for playback.

For installation and automatic updates, see the [marketplace README](https://github.com/scene-labs/scene-plugins#readme).
